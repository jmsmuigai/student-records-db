# Student Records API with FastAPI

## 📌 Project Overview
This is a Student Records Management API built with FastAPI and MySQL. It allows you to perform CRUD (Create, Read, Update, Delete) operations on student records using a RESTful API. This project is designed for efficient database management and can be scaled for larger educational applications.

---

## 🚀 Features
- FastAPI for high-performance web API development.
- MySQL for reliable and scalable database management.
- Secure database connections using environment variables.
- Well-structured project with separate files for models, database configuration, and API logic.
